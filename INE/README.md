# INE Security - Lab Walkthroughs & Practical Notes

This directory contains technical notes, practical exercises, and lab walkthroughs completed through [INE](https://ine.com) training paths and certification curricula.

---

## Directory Organization

Walkthroughs are organized by training pathway and functional domain.

```text
INE/
├── README.md
├── Penetration-Testing-Basics/
├── Web-Application-Pentest/
├── Advanced-Pentest-Concepts/
└── Cloud-Security/
```

- **Penetration-Testing-Basics/** — Foundational security assessments, networking, and service enumeration.
- **Web-Application-Pentest/** — Web application assessment techniques and vulnerability analysis.
- **Advanced-Pentest-Concepts/** — Advanced network testing, pivoting, and other penetration-testing concepts.
- **Cloud-Security/** — Cloud infrastructure security assessment and auditing.

## Documentation Standards

Each exercise follows the repository's standard [Walkthrough Template](../Templates/Walkthrough-Template.md).

Documentation focuses on:

- **Systematic Enumeration:** Recording methodical information-gathering steps.
- **Vulnerability Identification:** Explaining why a vulnerability exists in the target environment.
- **Proof of Concept:** Documenting verified commands and reproducible testing steps.
- **Defensive Countermeasures:** Describing mitigation and hardening recommendations.

## Academic Integrity & Responsible Use

- Do not copy or redistribute proprietary courseware, course slides, exam questions, or official solutions.
- Write notes in your own words, focusing on practical learning, methodology, and remediation.
- Sanitize sensitive hostnames, IP addresses, credentials, and other identifying artifacts where appropriate.
- Follow INE's applicable terms, policies, and assessment rules.
- Perform testing only in authorized lab environments or against systems for which you have explicit permission.
